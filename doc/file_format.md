## CSV/Excel
## Required
- `product_name`
- `product_description` (string) **or** `barcode`/`sku` (string)
- `category` (string: bakery / fruit_veg / chilled / ambient / other)
- `quantity` (number)
- `unit` (string: each / kg / pack)
- `available_from` (datetime)
- `available_until` (datetime)
- `best_before_date` (date)
### Optional
- `store_id` (string)
- `weight_kg` (number)
- `unit_price` (number)
- `total_value` (number)
- `surplus_reason` (string)
